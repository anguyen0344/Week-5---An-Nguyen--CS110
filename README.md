CS110 Week 5 – Beginner’s Field Guide

Project Theme

My theme is a Technology Field Guide for newcomers. My audience is a beginning CS110 student. The purpose of my website is to explain the main Week 1–4 ideas in a simple and interactive way.

Week 1–4 Recap

* Week 1 explains the learning process: ask a question, try an idea, check the result, and ask for help.
* Week 2 explains story, genre, and the visual, logical, and data hats.
* Week 3 introduces HTML, CSS, JavaScript, VS Code, Git, and GitHub.
* Week 4 explains the browser, name server, server, reusable npm packages, and a 3D scene.

An npm package is like a tool from a shared shelf. I can reuse it instead of building the same tool from the beginning.

How the Website Works

HTML provides the content and structure. CSS controls the colors, spacing, buttons, and layout. JavaScript creates the “Show me a tip” interaction and displays a visible result. Babylon.js creates and controls the Week 4 3D scene.

For my 3D revision, I changed the sphere diameter from 2 to 4. This made the sphere larger and showed how changing one JavaScript value changes an object on the page.

Peer Feedback and Revision
